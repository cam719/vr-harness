# Security & disclosure

This repository is research tooling for **authorized** security testing of
software you own or are permitted to test. It is non-destructive: it feeds inputs
to a parser under a sanitizer and records whether the parser faulted. It ships no
exploits and no crash inputs.

If you discover a vulnerability in third-party software using this tooling, please
follow that project's coordinated-disclosure process and keep details of unfixed
issues private until a fix is available.

To report an issue in this tooling itself, please open a GitHub issue.
